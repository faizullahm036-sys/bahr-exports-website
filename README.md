# Bahr Exports Website

A responsive business website developed for Bahr Exports to present
the company's export business, products, global reach, and contact
information.

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## Features

- Responsive navigation
- Animated hero section
- Product showcase
- Global reach section
- Company information section
- Contact form interface
- Scroll animations
- Interactive UI effects
